# 双形态支持实施计划

## 头部

- **目标**：按 spec 把模板升级为单模板双形态（专项 / 全局），spec 见 `docs/specs/2026-08-30-双形态支持-design.md`（同分支已提交，编号方案 A）。
- **架构**：llm-wiki 是纯文档 + 脚本仓库——四份 SKILL.md（`.agents/skills/`，给 LLM 读的操作契约）、双平台 bootstrap（`scripts/bootstrap.sh` / `bootstrap.ps1`）、Python 契约测试（`tests/`，unittest）、Markdown 文档。无构建、无依赖安装。
- **技术栈**：bash（macOS/Linux）、PowerShell 5.1+（Windows）、Python 3 标准库 unittest。
- **执行环境**：worktree `.worktrees/dual-mode/`，分支 `feat/dual-mode`（基线 `template` = v0.1.0，684584f）。全部提交打在此分支，消息前缀 `template: `。
- **全局约束**（自 spec 非目标逐字抄录）：
  - 不改动 `llm-wiki-for-work`（冻结的联邦成员，独立演进）。
  - 不支持一台机器多个全局实例（`~/.llm-wiki` 唯一）。
  - 不提供模式自动迁移脚本；切换步骤文档化，人工执行。
  - 不触碰 `wiki/`、`inputs/` 内容目录；wiki schema（`docs/schemas/wiki.md`）无数据结构变更。
- **补充执行约束**：bootstrap 幂等原则不变（只增不减）；锚句必须与本计划逐字一致（测试按它匹配）；凭证红线照旧。
